# Alex Morgan — Project Portfolio

A small, responsive personal website for sharing coding projects, screenshots, and code snippets. It uses plain HTML and CSS, so there is no build step or dependency installation.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Make it yours

- In `index.html`, replace the sample name, introduction, project descriptions, technology tags, email address, and project links with your own.
- Put screenshots in `assets/` (or a subfolder), then update each project’s `<img src>` and descriptive `alt` text. The included SVG previews are examples you can replace.
- Add a code example inside a project’s `<details class="snippet">` block using `<pre><code>…</code></pre>`. Add or remove project cards by copying an `<article class="project-card">` in the projects section.
- Adjust the layout and colors in `styles.css`.

The site is static and can be published with GitHub Pages or another static host.
